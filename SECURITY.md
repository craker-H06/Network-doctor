# Politique de sécurité

Network Doctor est un outil d'administration. Une correction prioritaire concerne tout contournement de l'autorisation de cible, toute injection dans les commandes système, ou tout diagnostic lancé sans cible explicite.

Les fonctions offensives (découverte d'Internet, balayage de ports, furtivité, exploitation) sont hors périmètre. Leur absence n'est pas un défaut.

Le modèle de menace et les contrôles actuels sont décrits dans [docs/securite.md](docs/securite.md).
